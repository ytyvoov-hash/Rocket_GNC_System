  Header: 0xAA 0xCC

  │ Byte │ Field      │ Type   │ Description                             │

  │  0   │ Header 1   │ uint8  │ 0xAA (sync)                             │

  │ 15   │ Cam Work   │ uint8  │ Camera connection (1=Running, 0=Fail)   │

  │ 18   │ Target H   │ uint8  │ Target pixel height (Divided by 10)     │
  │ 19   │ Fire Cmd   │ uint8  │ Fire command confirmation (1 or 0)      │
  │20-21 │ Zoom Lev   │ uint16 │ Optical/Digital zoom magnification      │
  │22-23 │ CRC16      │ uint16 │ CRC-16/CCITT of bytes 0-21 (LE)         │

  Encoding: float → int16 (× 100), Little-Endian
  Example:  angleX = 15.25° → ax = 1525 → [0xF5, 0x05]

  IPU State (Byte 16) Bitmask Layout:
    • Bits [0:2] : Main State (1=Idle, 2=Search, 3=Track)
    • Bits [3:5] : Find Count (0=Empty, 1=Single, 2=Multiple)
    • Bit  [6]   : Lock State (1=Locked, 0=Not Locked)

  Header: 0x55 0xAA

  ┌──────┬────────────┬────────┬─────────────────────────────────────────┐
  │ Byte │ Field      │ Type   │ Description                             │
  ├──────┼────────────┼────────┼─────────────────────────────────────────┤
  │  0   │ Header 1   │ uint8  │ 0x55 (sync)                             │
  │  1   │ Header 2   │ uint8  │ 0xAA (sync)                             │
  │  2   │ Stab Mode  │ uint8  │ Stabilization Mode (1=On, 0=Off)        │
  │  3   │ Cam Mode   │ uint8  │ Camera Mode / Data Reset Command        │
  │ 4-5  │ Yaw Ovr    │ int16  │ Manual Yaw override × 100 (LE)          │
  │ 6-7  │ Pitch Ovr  │ int16  │ Manual Pitch override × 100 (LE)        │
  │  8   │ Ctrl Cmd   │ uint8  │ HUD Control Command bitmask (see below) │
  │ 9-12 │ Timestamp  │ uint32 │ Uplink timestamp in ms (Sync clock)     │
  │13-17 │ Reserved   │ bytes  │ 0x00 padding for future expansion       │
  │18-19 │ CRC16      │ uint16 │ CRC-16/CCITT of bytes 0-17 (LE)         │
  └──────┴────────────┴────────┴─────────────────────────────────────────┘

  Ctrl Command (Byte 8) Bitmask Layout:
    • Bits [0:2] : Override Cmd (0=None, 1=Stop, 2=Search, 3=Track)
    • Bit  [4]   : Weapon Fire Request (1=Fire, 0=Safe)
    • Bit  [5]   : Ground Link Status (1=Connected, 0=Disconnected)

  CRC-16/CCITT  |  Polynomial: 0x1021  |  Init: 0x0000
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  uint16_t crc16(uint8_t *data, int count) {
      uint16_t crc = 0;
      for (int i = 0; i < count; i++) {
          crc ^= (uint16_t)data[i] << 8;
          for (int j = 0; j < 8; j++) {
              if (crc & 0x8000)
                  crc = (crc << 1) ^ 0x1021;
              else
                  crc <<= 1;
          }
      }
      return crc;
  }

  TX: CRC = crc16(buf, 22)  →  buf[22] = CRC & 0xFF,  buf[23] = CRC >> 8
  RX: CRC = crc16(buf, 18)  →  verify: (buf[19] << 8) | buf[18]
