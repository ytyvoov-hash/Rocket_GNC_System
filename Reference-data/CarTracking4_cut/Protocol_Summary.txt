  │ 4-5  │ Angle Y    │ int16  │ Target angle Y in degrees × 100 (LE)    │

  Encoding: float → int16 (× 100), Little-Endian
  Example:  angleX = 12.34° → ax = 1234 → [0xD2, 0x04]

  MCU Decode: float angleX = (int16_t)(buf[2] | (buf[3] << 8)) / 100.0f;

  ⚠ CRC byte order: TX = Little-Endian | RX = Big-Endian (high byte first)

  MCU Commands (RX Mode Cam):
    • 0xAC → Android starts detection
    • 0xE4 → Android stops detection

  CRC-16/CCITT  |  Polynomial: 0x1021  |  Init: 0x0000
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  uint16_t crc16(uint8_t *data, int count) {
      uint16_t crc = 0;
      for (int i = 0; i < count; i++) {
          crc ^= (uint16_t)data[i] << 8;
          for (int j = 0; j < 8; j++) {
              if (crc & 0x8000)
                  crc = (crc << 1) ^ 0x1021;
              else
                  crc <<= 1;
          }
      }
      return crc;
  }

  TX: CRC = crc16(buf, 14)  →  buf[15] = CRC & 0xFF,  buf[16] = CRC >> 8
  RX: CRC = crc16(buf, 7)   →  verify: (buf[8] << 8) | buf[7]
